# Maestría en Ciencia de Datos

Repositorio con los proyectos, prácticas y trabajos desarrollados durante la maestría.

## Autor

**Miguel Deza** — Bachiller en Ciencias de la Computación (UNSA, 2025), actualmente cursando la Maestría en Ciencia de Datos.

## Estructura

Cada práctica o proyecto vive en su propia carpeta, con su fuente (código, `.tex`, notebooks, etc.) y su entregable final:

```
maestria-ciencia-datos/
├── practica-01-Vs-Big-Data/
├── practica-02-etl-powerbi/
├── practica-03-weka/
└── ...
```

## Contenido

| Carpeta | Descripción | Curso |
|---|---|---|
| [`practica-01-Vs-Big-Data`](practica-01-Vs-Big-Data) | Análisis de las 3 V's del Big Data (Volumen, Velocidad, Variedad) aplicado a un caso real — estudio de caso Netflix, trabajo grupal | Introducción a Ciencia de Datos |
| [`practica-02-etl-powerbi`](practica-02-etl-powerbi) | Pipeline ETL en Power BI: integración de datos de un libro de Excel y un feed OData (Northwind), modelado de relaciones y visualización interactiva | Introducción a Ciencia de Datos |
| [`practica-03-weka`](practica-03-weka) | Pipeline visual de clasificación en Weka KnowledgeFlow (Random Forest, J48, Multilayer Perceptron) sobre el dataset Iris, con análisis estadístico y comparación de modelos | Introducción a Ciencia de Datos |
